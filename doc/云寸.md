# 云寸 — 程序入口与流程编排

> 源文件：`云寸.cpp`　|　所属层：入口（UI / 编排）
> 职责概述：程序唯一入口 `main()`，负责环境初始化、按顺序驱动"定位 → 实时天气 → 预警"三条业务、捕获异常，并彩色打印结果。

## 1. 概述

`云寸.cpp` 是整个程序的**唯一入口**，也是唯一**不应被当作库复用**的文件（当作库使用时须排除它，见根目录 `README.md`）。

它本身不包含任何网络或解析逻辑，只做三件事：

1. 初始化运行环境（控制台编码、cURL、数据目录、日志系统）；
2. 按顺序调用 `Weather` 的业务接口完成数据获取；
3. 捕获异常，并把结果彩色打印到控制台。

`main()` 内使用的主要对象：

| 对象 | 类型 | 说明 |

| `weatherInstant` | `Weather*` | 天气业务对象，`new` 创建；构造时设置请求头并记录时间戳 |

| 条件 | 颜色 | 标签 |
| --- | --- | --- |
| `<= 50` | green | 优 |

## 4. 主要接口

本文件只实现 `int main()`，其余为对外的调用：

| 接口 | 来源 | 说明 |
| --- | --- | --- |
| `SetConsoleOutputCP(CP_UTF8)` | Win32 | 控制台按 UTF-8 输出，配合 `/utf-8` 编译选项解决中文乱码 |
| `curl_global_init(CURL_GLOBAL_ALL)` | libcurl | 全局初始化 |
| `Tools::CheckIfDataFileExists()` | `Tools` | 创建 `%AppData%\yc` 并设定数据目录 |
| `Tools::String_GetCurrentTime()` | `Tools` | 取当前毫秒时间戳 |
| `Tools::InitLogSystem()` | `Tools` | 启动异步日志系统 |
| `Tools::ShutdownLogSystem()` | `Tools` | 停止日志系统并落盘 |
| `Weather::get_weather_kit(Type)` | `Weather` | 获取某类天气数据（下载 + 解析） |
| `Tools::log_write(...)` | `Tools` | 写日志 |
| `clr::<颜色>` / `clr::reset` | `colored_cout` | 彩色输出控制 |

## 5. 工作流程

1. `SetConsoleOutputCP(CP_UTF8)` —— 设定控制台输出编码；
2. `curl_global_init(CURL_GLOBAL_ALL)` —— 初始化 cURL；
3. `Tools::CheckIfDataFileExists()` —— 创建数据目录；
4. `Tools::InitLogSystem()` —— 启动异步日志系统；
5. `Tools::String_GetCurrentTime()` —— 取当前时间；
6. `new Weather(Type::instant)` —— 创建业务对象；
7. 在 `try` 中编排业务：
   - `res1 = get_weather_kit(Type::location)` —— IP 定位；
   - 若 `res1`：`get_weather_kit(Type::instant)` —— 实时天气；
   - 若 `res1`：`get_weather_kit(Type::warnings)` —— 天气预警；
   - 若 `!res1`：记错误日志并 `throw ycresult(ExcptType::curl, AddressMethod::back, ...)`；
8. `catch (const ycresult::ycresult& e)`：写日志；若 `AddressMethod` 为 `back` 或 `crash`，写致命日志 → `ShutdownLogSystem()` → `exit(1)`；
9. 打印：`system("cls")` 清屏后，依次输出更新日期/时间、城市、气温、天气、风向风速、AQI（分级上色）、预警、官网地址；
10. 收尾：`system("pause")` → `ShutdownLogSystem()` → `return 0`。

## 6. 依赖关系

- **上游依赖**：操作系统 Win32 控制台 API、libcurl。
- **下游被调用**：`Weather`（业务）、`Tools`（基础设施）、`colored_cout`（彩色输出）。

## 7. 注意事项 / 已知问题

- `std::stoi(weatherInstant->CurrentAQI)` 未加防护：AQI 字段非法时会抛未捕获异常导致崩溃（详见 `known_issues.md` 第 2 条）。
- `res2`、`res3` 是作用域受限且未被使用的多余变量，属代码整洁问题（详见 `known_issues.md` 第 11 条）。
- `weatherInstant` 以裸指针 `new` 创建且从未 `delete`（进程退出由系统回收，影响有限）。
- 文件末尾的 `// 运行程序...` 注释为 Visual Studio 模板残留，可忽略。
